# 删除消费者

## 接口信息

- **URL**: `/v1/consumers/{name}`
- **方法**: `DELETE`
- **描述**: 根据名称删除指定的消费者。

## 请求参数

### Path 参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | String | 是 | 要删除的消费者名称，不可为空 |

## 响应

删除成功时返回 HTTP `204 No Content`，无响应体。

## 请求示例

```bash
curl -X DELETE http://localhost:8080/v1/consumers/my-consumer
```

## 错误码

| HTTP 状态码 | 说明 |
|-------------|------|
| 204 | 删除成功（无响应体） |
| 500 | 内部服务错误 |
